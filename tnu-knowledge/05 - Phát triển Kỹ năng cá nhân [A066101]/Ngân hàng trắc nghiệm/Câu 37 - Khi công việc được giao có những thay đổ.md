# ❓ Phát triển Kỹ năng cá nhân [A066101] - Câu 37

#### Câu 37: Khi công việc được giao có những thay đổi đáng kể về phạm vi và cấp độ, xuất hiện nguy cơ quá tải khiến không thể đảm đương được công việc thì cấp dưới cần làm gì?

- A. Tạo diễn đàn chia sẻ bức xúc với các đồng nghiệp khác
- B. Im lặng, không làm gì vì cấp trên đã giao việc thì chắc phải biết vấn đề
- C. Buông xuôi, làm được đến đâu thì làm
- D. Chủ động đề xuất với cấp trên về phương án thực hiện và nói rõ giới hạn khả năng của mình

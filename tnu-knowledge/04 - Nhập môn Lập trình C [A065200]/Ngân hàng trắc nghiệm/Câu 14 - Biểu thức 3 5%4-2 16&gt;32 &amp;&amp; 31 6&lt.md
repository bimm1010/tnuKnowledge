#### Câu 14: Biểu thức: 3*5%4-2*16&gt;32 &amp;&amp; 31/6&lt;7 cho kết quả bằng bao nhiêu?

- A. False
- B. 1
- C. True
- D. 0

> **✅ ĐÁP ÁN ĐÚNG:** `0`
> *Giải thích:* 3*5%4-2*16&gt;32 &amp;&amp; 31/6&lt;7 = 15%4-32 &gt; 32 &amp;&amp; 5&lt;7 = -29&gt;32 &amp;&amp; 5&lt;7 = 0 &amp;&amp; 1 = 0

# ❓ Cấu trúc Dữ liệu và Giải thuật [A050900] - Câu bổ sung 18

**Hỏi:** Cho biểu thức số học dạng thông thường: a * (b + c) - d/e Đâu là biểu diễn biểu thức này dưới dạng biểu thức Balan?

**Các lựa chọn:**
- A. abc + * de /-
- B. ab * c + de /-
- C. abc +* de -/
- D. abc *+ de /-

> **✅ ĐÁP ÁN ĐÚNG:** `abc + * de /-`

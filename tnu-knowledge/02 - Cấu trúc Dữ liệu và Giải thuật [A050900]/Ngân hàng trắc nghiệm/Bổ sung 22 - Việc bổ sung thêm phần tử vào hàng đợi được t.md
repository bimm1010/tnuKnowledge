# ❓ Cấu trúc Dữ liệu và Giải thuật [A050900] - Câu bổ sung 22

**Hỏi:** Việc bổ sung thêm phần tử vào hàng đợi được thực hiện bằng đoạn mã void ENQUEUE(QUEUE_ARRAY q, ELEMENT e) if (q.T == q.capacity-1) q.T=0; else ... q.ele[q.T]=e; q.S=q.S+1;

**Các lựa chọn:**
- A. q.T=q.T-1
- B. q.T=1
- C. q.T=q.S+1
- D. q.T=q.T+1

> **✅ ĐÁP ÁN ĐÚNG:** `q.T=q.T+1`
